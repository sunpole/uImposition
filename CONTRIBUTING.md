<h2>Русский</h2>

<p>uImposition является публично разрабатываемым, но проприетарным проектом, ориентированным на будущую коммерциализацию.</p>

<h3>Можно</h3>
<ul>
<li>создавать issue с описанием ошибки;</li>
<li>предлагать улучшения интерфейса и документации;</li>
<li>сообщать о производственных случаях, которые нужно учитывать;</li>
<li>предлагать тестовые данные без конфиденциальной информации.</li>
</ul>

<h3>Pull request</h3>
<p>Перед крупной реализацией желательно сначала согласовать задачу в issue. Принятие pull request не означает передачу лицензии на весь проект и не превращает проект в open source.</p>

<h3>Требования</h3>
<ul>
<li>русская и английская документация обновляются одновременно;</li>
<li>новые параметры добавляются в конфигурацию;</li>
<li>производственные формулы не меняются без объяснения;</li>
<li>недопечатка и неправильный оборот недопустимы;</li>
<li>изменения должны сопровождаться тестами.</li>
</ul>

<h2>English</h2>

<p>uImposition is developed publicly but remains a proprietary project intended for future commercialization.</p>

<h3>You may</h3>
<ul>
<li>open issues describing defects;</li>
<li>suggest interface and documentation improvements;</li>
<li>describe production cases that should be supported;</li>
<li>provide test data that contains no confidential information.</li>
</ul>

<h3>Pull requests</h3>
<p>Major implementation work should normally be discussed in an issue first. Acceptance of a pull request does not relicense the entire project or make the project open source.</p>

<h3>Requirements</h3>
<ul>
<li>Russian and English documentation must remain synchronized;</li>
<li>new settings belong in the central configuration;</li>
<li>production formulas must not change without explanation;</li>
<li>underproduction and invalid back forms are prohibited;</li>
<li>changes should include appropriate tests.</li>
</ul>

## Авторство вклада / Contribution authorship

Отправляя вклад, автор подтверждает, что имеет право его предоставить и разрешает владельцу проекта использовать вклад в составе uImposition, включая будущие коммерческие версии. Для значительных внешних вкладов перед объединением может потребоваться отдельное письменное соглашение.

By submitting a contribution, the author confirms that they have the right to provide it and permits the project owner to use it as part of uImposition, including future commercial editions. A separate written agreement may be required before accepting substantial external contributions.
