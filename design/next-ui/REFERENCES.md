# Reference products for Next UI

Research checkpoint: 2026-08-01.

The prototype does not copy any product. It studies proven interaction patterns from mature open-source business applications.

## Twenty CRM

Study:
- clean object navigation;
- dense table/list hierarchy;
- quick actions and command-oriented workflow;
- restrained CRM visual language.

Repository: `https://github.com/twentyhq/twenty`

## Plane

Study:
- fast workspace movement;
- compact status language;
- list density;
- persistent context while switching sections.

Repository: `https://github.com/makeplane/plane`

## NocoDB

Study:
- grid density;
- column visibility and views;
- record detail without destroying table context;
- internal horizontal scrolling on mobile.

Repository: `https://github.com/nocodb/nocodb`

## ERPNext / Frappe

Study:
- business workspace architecture;
- mature list/form patterns;
- module navigation;
- practical ERP information density.

Repositories:
- `https://github.com/frappe/erpnext`
- `https://github.com/frappe/frappe`

## Appsmith

Study:
- internal-tool composition;
- panel and table layouts;
- responsive operator dashboards;
- configurable actions.

Repository: `https://github.com/appsmithorg/appsmith`

## Directus

Study:
- collection navigation;
- filter and table structure;
- side detail patterns;
- clear content hierarchy.

Repository: `https://github.com/directus/directus`

## Applied conclusion

The first prototype combines:
- CRM-like global navigation;
- ERP-like persistent business context;
- database-grid row density;
- internal-tool panel composition;
- a mobile dock and sticky table columns designed specifically for uImposition.
