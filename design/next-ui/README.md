# uImposition Next UI prototype

Standalone design-only prototype for a new operator-first UI system.

## Preview

Open the exact checkpoint through a static raw preview service:

`https://raw.githack.com/sunpole/uImposition/8352aba911983c20f21a69d622731d89ef207740/design/next-ui/index.html`

## Scope

- new layout and visual system from scratch;
- no imports from current `/app/` CSS or JavaScript;
- no `m3.css`;
- no production solver integration;
- current published `/app/` remains unchanged;
- current UI checkpoint is preserved in `archive/ui-current-v7-2026-08-01`.

## Prototype interactions

- persistent top navigation;
- mobile bottom dock;
- order, plans, layout, forms, cost and export screens;
- compact one-line order table;
- sticky index/name columns;
- internal horizontal table scrolling on narrow screens;
- comfortable, compact and ultra density modes;
- economy mode;
- command palette;
- mobile preset panel;
- selected row state.

## Required review widths

320, 360, 390, 430, 768, 1024, 1366×768, 1440 and 1920×1080.

This checkpoint is a design prototype, not a replacement for the production app.
