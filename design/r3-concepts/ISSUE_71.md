# Issue #71 coverage

The interactive concept page covers:

- three structurally different desktop directions;
- 1440 and 1024 preview widths;
- independent 390 and 360 mobile layouts;
- one and five product rows;
- sheet/press preset switcher;
- local preset editor;
- ready, calculating and field-error states;
- last-valid-result messaging;
- paper/forms/plates/passes/cost comparison;
- recommendation separated from operator selection;
- selected layout preview;
- path to scheme/PDF actions.

It is intentionally disconnected from production code and exists only to make the R3 direction decision inspectable.
