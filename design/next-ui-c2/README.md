## Corrections

- real HTML table rows replace CSS Grid auto-placement;
- switching Order / Print / Result / All hides table columns without changing row structure;
- the staircase layout is structurally impossible;
- row height remains 19 px;
- number column starts at two digits and expands when the order count exceeds 99;
- name column is compact: 112 px desktop, 88 px mobile, 80 px narrow mobile;
- global page overflow is forbidden;
- horizontal scrolling is isolated inside the table container;
- selected row information and touch-sized actions remain above the mobile dock;
- Calculation, Montage, Print and Output screens are interactive design views;
- HTML, CSS and JavaScript are separate files.
