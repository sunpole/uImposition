# uImposition 0.7.0-alpha.4 — свой оборот: одна форма, два прогона

В M7.4 чужой оборот и свой оборот стали отдельными проверяемыми производственными стратегиями.

Контрольный заказ:

- четыре разных изделия A6;
- две страницы;
- цветность `1+1`;
- по `4000` экземпляров каждого изделия;
- печатная область `608 × 431 мм`;
- сетка `4 × 4`.

Оба способа дают одинаковый производственный объём:

- `1000` физических листов;
- `2000` листопрогонов;
- нулевая недопечатка;
- нулевой перетираж.

Разница появляется в формах:

| Метрика | Чужой оборот | Свой оборот |
|---|---:|---:|
| Layout-формы | 2 | 1 |
| Цветовые пластины при 1+1 | 2 | 1 |
| Итог при контрольном прайсе | 175,08 BYN | 160,08 BYN |

При цене `15 BYN` за пластину и нулевой стоимости подготовки формы свой оборот экономит ровно `15 BYN`. Бумага и число прогонов в этом контрольном примере не меняются.

Программа отдельно проверяет:

- симметричную общую форму;
- чётное число колонок;
- зеркальные пары лицевой и оборотной страниц;
- направление горизонтального переворота;
- готовые изделия после двух прогонов;
- формы, пластины, листы, прогоны и недопечатку.

На основной странице доступны режимы:

- только чужой оборот;
- сравнить оба;
- только свой оборот.

Переключение режима фильтрует уже проверенные результаты и не запускает повторную генерацию геометрии.

## Технологическая граница

Этот релиз подтверждает горизонтальный work-and-turn для проверенного контрольного случая. Он пока не является общим автоматическим поиском своего оборота для любого заказа. Перед производством оператор должен проверить захват, боковой упор, приводку и допустимость переворота для конкретной печатной машины.

Контрольные цены используются только для evidence. Рабочие цены вводит оператор.
