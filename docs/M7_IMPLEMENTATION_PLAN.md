# M7 — иерархия решений, свой оборот и сравнение вариантов

## Статус

План следующего этапа после объединения `0.6.0-alpha`. M6 доказал минимум физической бумаги, но одновременно показал, почему одной цели недостаточно: бумага снизилась с `3395` до `3305`, а число layout-форм выросло с `8` до `112`.

M7 превращает оптимизатор из «найти один минимум» в рабочий инструмент оператора, который показывает несколько допустимых решений, мгновенно пересортировывает их по выбранной иерархии и оставляет окончательный выбор пользователю.

## 1. Жёсткие ограничения

Эти правила находятся выше любой пользовательской сортировки и не могут быть перемещены:

1. недопечатка равна `0`;
2. все позиции находятся внутри печатной области;
3. лицо, оборот, страницы и направления валидны;
4. оборот соответствует выбранной технологии;
5. знак `-` допустим только на обороте;
6. каждый выбранный монтаж материализуется и проходит production report;
7. расчёт не скрывает усечённое пространство поиска;
8. вариант со своим оборотом показывается только при выполнении его геометрических и технологических условий.

## 2. Перетаскиваемая иерархия целей

Пользователь видит компактный список целей и меняет порядок drag-and-drop или кнопками вверх/вниз.

Порядок по умолчанию:

1. минимум физической бумаги;
2. минимум layout-форм;
3. минимум цветовых пластин;
4. минимум перетиража готовых файлов;
5. минимум суммарного перетиража печатных пар;
6. минимум листопрогонов;
7. минимум разделённых заказов;
8. минимум монтажей;
9. компактная группировка одинаковых изделий;
10. минимум разных заказов на одном монтаже.

Пользователь может, например, поднять «минимум форм» выше «минимума бумаги». Рекомендуемый вариант должен измениться сразу, без повторного ручного запуска.

### Правило сравнения

Основной режим — лексикографический:

```text
сначала сравнить варианты по цели №1;
при равенстве — по цели №2;
затем по цели №3 и далее.
```

Дополнительная взвешенная оценка допустима только как пояснение и не должна подменять прозрачную иерархию.

## 3. Пересчёт в реальном времени

Перемещение приоритета не должно заново перебирать миллионы раскладок.

Архитектура:

1. оптимизатор формирует набор допустимых существенно отличающихся решений;
2. для каждого решения заранее вычисляются все метрики;
3. Pareto-дубли удаляются;
4. интерфейс хранит готовый набор вариантов;
5. изменение порядка целей только мгновенно пересортировывает этот набор;
6. рекомендованный вариант, разницы и подсветка обновляются в том же кадре интерфейса.

Если пользователь изменил исходные заказы, лист или технологию оборота, выполняется новый расчёт. Если изменился только порядок целей, выполняется только повторное ранжирование.

## 4. Чужой и свой оборот

### 4.1. Чужой оборот

- отдельная layout-форма лица;
- отдельная layout-форма оборота;
- оборот строится из утверждённого лица;
- обычный двухсторонний монтаж использует `2` layout-формы;
- при 1+1 обычно требуется `2` цветовые пластины;
- при 4+4 обычно требуется `8` цветовых пластин.

### 4.2. Свой оборот

Одна и та же форма используется для первого и второго прогона после технологического переворота листа.

Обязательные проверки:

- геометрия совместима с выбранным направлением переворота;
- парные половины листа симметричны;
- после переворота каждая лицевая позиция получает правильный оборот;
- число изделий каждого вида после двух прогонов рассчитано без двойного счёта;
- бумага, формы, цветовые пластины и листопрогоны показываются отдельно;
- программа объясняет операцию переворота и возможное влияние на резку/сборку.

### 4.3. Режим выбора

В настройках заказа или расчёта:

- `Только чужой оборот`;
- `Разрешить свой и чужой оборот`;
- `Только свой оборот`, если оператор сознательно ограничивает поиск.

По умолчанию программа сравнивает оба режима, но не выбирает свой оборот автоматически без явного объяснения.

## 5. Контрольный кейс своего оборота

Четыре разных вида A6:

```text
формат: 105 × 148 мм
страницы: 2
цветность: 1+1
тираж каждого вида: 4000
печатная область: 608 × 431 мм
сетка после поворота: 4 × 4 = 16
```

### Чужой оборот

Лицо содержит по `4` позиции каждого из четырёх видов. Оборот — отдельная зеркальная форма.

```text
тираж листа:          1000
физическая бумага:    1000
листопрогоны:         2000
layout-формы:         2
цветовые пластины 1+1: 2
перетираж:            0
```

### Свой оборот

Одна форма содержит для каждого вида по `2` лицевые и `2` оборотные позиции. После второго прогона той же формой и переворота листа получается по `4` готовых экземпляра каждого вида с одного физического листа.

```text
тираж листа:          1000
физическая бумага:    1000
листопрогоны:         2000
layout-формы:         1
цветовые пластины 1+1: 1
перетираж:            0
```

В этом кейсе бумага и листопрогоны одинаковы, но свой оборот уменьшает layout-формы `2 → 1` и цветовые пластины `2 → 1`. Поэтому:

- при приоритете «минимум бумаги» варианты равны по первой цели;
- при следующем приоритете «минимум форм» выигрывает свой оборот;
- оператор всё равно видит технологическое предупреждение и обе схемы.

## 6. Все варианты для индивидуального решения

Программа не выводит миллионы сырых комбинаций. Она показывает все существенно отличающиеся допустимые решения после удаления полных дублей и доминируемых вариантов.

Обязательные закреплённые варианты:

- рекомендованный по текущей иерархии;
- минимум бумаги;
- минимум layout-форм;
- минимум цветовых пластин;
- минимум перетиража;
- минимум листопрогонов;
- минимум разделённых заказов;
- лучший вариант только с чужим оборотом;
- лучший вариант со своим оборотом;
- удобная компактная сборка.

Пользователь может включить режим `Показать все Pareto-варианты` и раскрыть полный список оставшихся решений.

## 7. Что показывать у каждого варианта

В одной компактной строке:

- название и статус;
- способ оборота;
- физические листы;
- монтажи;
- layout-формы;
- цветовые пластины;
- листопрогоны;
- перетираж готовых файлов;
- перетираж печатных пар;
- количество разделённых заказов;
- число разных заказов на одном монтаже;
- короткое объяснение преимущества и цены.

При выборе варианта справа или ниже открываются:

- все схемы лица/оборота;
- вклад каждого монтажа;
- список разделённых заказов;
- точные тиражи;
- сравнение с текущим выбранным вариантом.

## 8. Сравнение «что лучше / что хуже»

При переключении варианта интерфейс показывает дельты:

```text
бумага:            −90
layout-формы:      +104
цветовые пластины: +...
листопрогоны:      −180
перетираж пар:     −1440
разделённые заказы:+...
```

Положительная или отрицательная дельта не окрашивается автоматически как абсолютное добро/плохо. Оценка зависит от текущей иерархии. Например, `+1 форма` может быть допустимой ценой за `−500 листов`.

## 9. Компактность интерфейса

M7 не должен увеличивать текущую длинную страницу ещё сильнее.

### Desktop

- фиксированная компактная панель приоритетов;
- одна строка на вариант вместо крупных карточек;
- закреплённая строка заголовков;
- основные числа видны без раскрытия;
- детали, схемы и объяснения раскрываются по требованию;
- переключатель «Только различия»;
- таблица может сортироваться по любой метрике.

### Mobile

- верхняя компактная сводка выбранного варианта;
- приоритеты меняются кнопками вверх/вниз, drag-and-drop остаётся дополнительным;
- варианты представлены плотным списком;
- метрики, которые не помещаются, открываются в нижней панели или горизонтальном сравнении;
- раскрытие одной схемы не раскрывает все остальные;
- интерфейс не дублирует длинные пояснения.

## 10. Компактность самой раскладки

Отдельно от компактности интерфейса существует производственная цель:

- одинаковые позиции рядом;
- минимальное число разорванных блоков;
- меньше разных заказов на одном монтаже;
- понятный row-major порядок;
- удобная резка и сборка.

Эта цель является изменяемым приоритетом, но не может нарушать жёсткие ограничения или создавать недопечатку.

## 12. Порядок реализации

### M7.1 — модель целей

- неизменяемый список целей;
- drag/drop ordering model без DOM;
- лексикографический comparator;
- тесты перестановок и равенств.

### M7.2 — нормализованные метрики вариантов

- бумага;
- layout-формы;
- цветовые пластины;
- листопрогоны;
- два вида перетиража;
- разделённые заказы;
- компактность блоков.

### M7.3 — свой оборот

- чистая модель work-and-turn;
- геометрические ограничения;
- материализация одного и того же plate layout для двух прогонов;
- контрольный A6 1+1 кейс `4 × 4000`;
- независимая проверка готового количества.

### M7.4 — Pareto-набор

- удаление полных дублей;
- удаление доминируемых вариантов;
- обязательное сохранение крайних решений;
- объяснение, почему вариант остался в наборе.

### M7.5 — компактный интерфейс

- редактор приоритетов;
- мгновенная пересортировка;
- таблица вариантов;
- сравнение дельт;
- desktop/mobile Chromium evidence.

## 13. Приёмка M7

- перестановка целей мгновенно меняет рекомендованный вариант;
- жёсткие ограничения нельзя переместить или отключить;
- один набор решений ранжируется без повторной генерации;
- A6 `4 вида × 4000`, 2 страницы, 1+1 показывает чужой и свой оборот;
- свой оборот в контрольном кейсе сохраняет `1000` листов и `2000` прогонов, но сокращает формы и пластины `2 → 1`;
- пользователь видит минимум бумаги, минимум форм и все Pareto-варианты;
- каждая строка показывает, что стало лучше и что хуже;
- компактный desktop/mobile UI проходит Chromium;
- итоговый выбранный вариант повторно проходит production report.
