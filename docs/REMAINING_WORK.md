# Что не должно потеряться

- оператор выбирает решение, программа не скрывает альтернативы;
- приоритеты меняются без повторной генерации;
- стоимость — прозрачная цель, не скрытый коэффициент;
- цены вводит оператор;
- свой и чужой оборот сравниваются честно;
- недопечатка запрещена;
- layout-формы и цветовые пластины не смешиваются;
- manual mixed-format fixture не выдаётся за automatic packing;
- последовательные пары не выдаются за фальцевальный спуск;
- история и архивы сохраняются;
- каждый release получает самостоятельный immutable checkpoint.
