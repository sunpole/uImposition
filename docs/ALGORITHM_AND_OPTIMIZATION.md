# Алгоритм и оптимизация / Algorithm and Optimization

## Русская версия

### 1. Поток расчёта

1. Нормализовать входные данные.
2. Определить размер до/после зачистки.
3. Вычесть непечатные поля.
4. Построить допустимые геометрии.
5. Разбить каждый файл на печатные пары.
6. Сформировать кандидаты лицевых монтажей.
7. Назначить тиражи монтажей.
8. Отбросить варианты с недопечаткой.
9. Автоматически построить обороты.
10. Проверить страницы, зеркальность и стрелки.
11. Рассчитать метрики.
12. Сформировать набор существенно отличающихся лучших вариантов.
13. Отсортировать их по иерархии пользователя.
14. Отрисовать выбранный вариант и подготовить PDF.

### 2. Основные формулы

Для пары `i` и монтажа `m`:

`Q_i = Σ(n_i,m × T_m)`

где:

- `Q_i` — напечатанный тираж пары;
- `n_i,m` — количество повторов пары на монтаже;
- `T_m` — тираж физического листа монтажа.

Ограничение:

`Q_i ≥ D_i`

Перетираж:

`O_i = Q_i − D_i`

Бумага:

`Paper = Σ(T_m)`

Для чужого оборота:

`Forms = 2 × Impositions`

Листопрогоны при двухсторонней печати:

`PressPasses = 2 × Paper`

### 3. Иерархическая оценка

Приоритеты не суммируются в одну непрозрачную цифру. Используется лексикографическое сравнение.

Пример порядка:

1. бумага;
2. формы;
3. перетираж;
4. разбрасывание.

Вариант с меньшей бумагой выигрывает независимо от остальных метрик. Остальные метрики сравниваются только при равенстве бумаги.

### 4. Альтернативные решения

Кроме рекомендуемого варианта сохраняются лучшие решения по отдельным целям. Формируется компактный набор Парето: вариант не показывается, если другой вариант одновременно не хуже по всем ключевым метрикам и лучше хотя бы по одной.

### 5. Группировка

Одинаковые позиции собираются в непрерывные блоки построчно. Но группировка является мягким приоритетом и может уступать экономии бумаги.

### 6. Построение оборота

Оборот создаётся детерминированно из лица. Для строки из четырёх столбцов:

`[A, B, C, D] → [back(D), back(C), back(B), back(A)]`

Строки не меняются местами.

### 7. Безопасность расчёта

Ни один вариант не может быть рекомендован, пока не пройдены все жёсткие проверки. Ошибка в одной проверке блокирует экспорт выбранного варианта.

## English version

### Calculation pipeline

1. Normalize input data.
2. Resolve before-trim and post-trim sheet sizes.
3. Subtract non-printable press margins.
4. Generate valid placement geometries.
5. Convert each file into print pairs.
6. Generate front-imposition candidates.
7. Assign run lengths.
8. Reject all underproducing candidates.
9. Derive back forms automatically.
10. Validate pages, mirroring and arrows.
11. Calculate metrics.
12. Build a compact set of materially different best solutions.
13. Sort according to the user-defined hierarchy.
14. Render the selected solution and export PDF.

The quantity, paper, plate and press-pass formulas are identical to the Russian section above. Candidate comparison is lexicographic, and a Pareto-style filter removes alternatives that are unambiguously worse on all key metrics.
