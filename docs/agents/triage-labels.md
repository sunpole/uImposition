# Triage labels

The installed skills use five canonical triage roles.

| Skill role | uImposition label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the request |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent |
| `ready-for-human` | `ready-for-human` | Requires direct human implementation or decision |
| `wontfix` | `wontfix` | Will not be actioned |

The right-hand labels are the project defaults. They may be changed later without reinstalling the skills.
