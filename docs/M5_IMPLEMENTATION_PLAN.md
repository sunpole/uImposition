# M5 — PDF-экспорт / PDF export

## Статус / Status

Рабочий план ветки `m5/0.5.0-alpha`. Текущая публичная версия остаётся `0.4.0-alpha`, пока PDF не будет создан, отрисован и визуально проверен.

Working plan for `m5/0.5.0-alpha`. The public version remains `0.4.0-alpha` until PDF output is generated, rendered, and visually verified.

## Жёсткие требования / Hard requirements

- основной PDF содержит только схемы;
- одна страница PDF = одна схема;
- порядок: лицо, оборот для каждого монтажа;
- четыре монтажа дают ровно восемь страниц;
- отчёт не смешивается со схемами и экспортируется отдельным PDF;
- экспорт разрешён только для валидных схем и production-ready отчёта;
- русский и английский режимы меняют подписи, но не порядок и числа;
- пропорции схемы сохраняются;
- PDF после создания обязательно рендерится в PNG и проверяется.

## Этапы / Stages

### M5.1 — чистая модель документа

- централизованные PDF-настройки в `src/config.js`;
- `src/pdf-document-model.js` без DOM и PDF-библиотеки;
- восемь логических страниц схем;
- безопасные имена `LIST-01_FRONT.pdf` и далее;
- отдельная модель отчёта;
- режимы A4, пропорции листа и пользовательский формат;
- Node-тесты порядка, количества и ошибок.

### M5.2 — renderer

- выбрать браузерную библиотеку после проверки лицензии, размера и кириллицы;
- одна функция получает готовую модель и создаёт PDF bytes;
- никакой производственной арифметики внутри renderer;
- встроенный шрифт или системно независимый способ вывода кириллицы;
- схема вписывается без обрезки и искажения.

### M5.3 — проверка

- создать контрольный PDF схем;
- создать отдельный PDF отчёта;
- проверить структуру и количество страниц;
- отрендерить все страницы в PNG;
- проверить отсутствие обрезки, наложений, чёрных квадратов и сломанной кириллицы;
- desktop/mobile Chromium проверяет кнопки и загрузку;
- uNews получает новый реальный скриншот PDF-функции.

## Модель страниц / Page model

```text
1  ЛИСТ-1_ЛИЦО
2  ЛИСТ-1_ОБОРОТ
3  ЛИСТ-2_ЛИЦО
4  ЛИСТ-2_ОБОРОТ
5  ЛИСТ-3_ЛИЦО
6  ЛИСТ-3_ОБОРОТ
7  ЛИСТ-4_ЛИЦО
8  ЛИСТ-4_ОБОРОТ
```

English uses the same order with `SHEET-N_FRONT/BACK` labels.

## Режимы страницы / Page modes

- `a4`: 210 × 297 мм, схема вписывается с полями;
- `sheetProportional`: модель хранит пропорции исходного листа, окончательный размер выбирает renderer;
- `custom`: пользователь задаёт ширину и высоту страницы;
- во всех режимах используется `contain` и сохраняются пропорции.

## Отдельный отчёт / Separate report

Модель отчёта содержит три независимых раздела:

1. сводные итоги;
2. таблица файлов;
3. таблица печатных пар.

Фактическая пагинация длинных таблиц выполняется renderer-ом и отдельно тестируется. Отчёт не добавляется девятой страницей в PDF схем.

## Критерии первого патча / First-patch acceptance

- 4 контрольных монтажа → ровно 8 страниц;
- каждая логическая страница содержит ровно одну схему;
- порядок полностью соответствует ТЗ;
- безопасные имена стабильны и имеют ведущий ноль;
- A4, пропорциональный и custom режимы валидируются;
- повреждённые или непроверенные схемы отклоняются;
- invalid production report не попадает в PDF-модель;
- модель схем и модель отчёта имеют разные имена файлов;
- код не зависит от DOM и проходит Node built-in tests.
