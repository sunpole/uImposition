# M5 — PDF-экспорт / PDF export

## Статус / Status

Функциональная реализация завершена в ветке `m5/0.5.0-alpha`, PR №8. Версия кандидата — `0.5.0-alpha`. Оба PDF созданы настоящим Chromium, структурно проверены, прочитаны `pdfinfo`, полностью отрендерены Poppler и просмотрены вручную.

Functional implementation is complete in `m5/0.5.0-alpha`, PR #8. Candidate version: `0.5.0-alpha`. Both PDFs were generated by real Chromium, structurally validated, read by `pdfinfo`, fully rendered by Poppler, and manually reviewed.

## Реализованные жёсткие требования / Implemented hard requirements

- основной PDF содержит только схемы;
- одна страница PDF = одна схема;
- порядок: лицо, оборот для каждого монтажа;
- четыре монтажа дают ровно восемь страниц;
- отчёт экспортируется отдельным шестистраничным PDF;
- экспорт разрешён только для валидных схем и production-ready отчёта;
- русский и английский режимы меняют подписи, но не порядок и числа;
- пропорции схемы сохраняются;
- каждый PDF после создания скачивается, проверяется и полностью рендерится в PNG.

## Реализация / Implementation

### M5.1 — чистая модель документа, завершено

- `CONFIG.pdf` централизует режимы, размеры, DPI, JPEG quality и имена;
- `pdf-document-model.js` не использует DOM;
- создаёт восемь логических страниц схем;
- создаёт отдельную модель отчёта;
- поддерживает A4, пропорции листа и пользовательский формат;
- отклоняет непроверенные схемы и invalid report.

### M5.2 — PDF writer и Canvas-renderers, завершено

- `pdf-binary.js` — собственный dependency-free PDF 1.4 writer;
- каждая Canvas-страница сохраняется как JPEG и становится отдельным PDF Page/XObject;
- `pdf-scheme-renderer.js` рисует схемы, кириллицу и стрелки;
- `pdf-report-renderer.js` рисует сводку и таблицы;
- `pdf-export-ui.js` предоставляет две независимые кнопки скачивания;
- производственная арифметика внутри renderer отсутствует;
- CDN, runtime-пакеты и распространение font-файлов не требуются.

### M5.3 — проверка, завершено

- Chromium скачивает оба документа;
- Playwright проверяет имя, `%PDF`, `%%EOF` и число Page-объектов;
- `pdfinfo` подтверждает A4 и количество страниц;
- Poppler рендерит все страницы в PNG;
- число PNG сравнивается с числом PDF-страниц;
- desktop/mobile интерфейс проверяется отдельно;
- все 14 страниц просмотрены вручную.

## Модель страниц схем / Scheme page model

```text
1  ЛИСТ-1_ЛИЦО
2  ЛИСТ-1_ОБОРОТ
3  ЛИСТ-2_ЛИЦО
4  ЛИСТ-2_ОБОРОТ
5  ЛИСТ-3_ЛИЦО
6  ЛИСТ-3_ОБОРОТ
7  ЛИСТ-4_ЛИЦО
8  ЛИСТ-4_ОБОРОТ
```

English uses the same order with `SHEET-N_FRONT/BACK` labels.

## Режимы страниц схем / Scheme page modes

- `a4`: `210 × 297 мм`;
- `sheetProportional`: длинная сторона `297 мм`, отношение сторон берётся из фактического листа;
- `custom`: пользователь задаёт ширину и высоту;
- во всех режимах используется `contain` и сохраняются пропорции.

## Отдельный отчёт / Separate report

`uImposition-production-report.pdf` содержит `6` страниц A4:

1. сводные итоги;
2. файлы 1–16;
3. файлы 17–20;
4. печатные пары 1–12;
5. печатные пары 13–24;
6. печатные пары 25–35.

Отчёт не добавляется девятой страницей в PDF схем.

## Проверенный результат / Verified result

- `uImposition-schemes.pdf`: `8` страниц;
- `uImposition-production-report.pdf`: `6` страниц;
- всего проверено и отрендерено: `14` страниц;
- A4 MediaBox: приблизительно `595.276 × 841.89 pt`;
- кириллица, стрелки, номера страниц, таблицы и длинные вклады читаются;
- обрезка, чёрные квадраты, сломанные глифы и пересечение заголовков отсутствуют.

## Граница / Boundary

M5 экспортирует уже заданные и проверенные монтажи. Генерация альтернатив, автоматический подбор тиражей и доказанный минимум бумаги относятся к M6.
