## Что требуется вручную / Manual action required

Текущий GitHub-коннектор умеет создавать и изменять файлы, но не предоставляет изменение полей **About**, описания, сайта и topics. Эти метаданные нужно один раз внести владельцу репозитория вручную.

The current GitHub connector can create and update files, but it cannot edit the repository **About** metadata, description, website or topics. The repository owner must enter these values once manually.
