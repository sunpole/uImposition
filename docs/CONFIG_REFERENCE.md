# Справочник конфигурации / Configuration Reference

## Основной принцип

Все изменяемые производственные параметры и интерфейсные значения находятся в `src/config.js`. Модули не должны содержать скрытые значения, влияющие на результат.

## Группы конфигурации

| Группа | Назначение / Purpose |
|---|---|
| `app` | версия, язык, единицы |
| `sheetPresets` | форматы листов |
| `sheetTrim` | зачистка |
| `pressMargins` | непечатные поля |
| `productPresets` | A4/A5/A6 |
| `bleedPresets` | выпуски |
| `cutting` | промежутки и общий рез |
| `turnModes` | способы переворота |
| `orientation` | стрелки |
| `fillOrder` | порядок ячеек |
| `hardConstraints` | обязательные правила |
| `optimization` | приоритеты и лимиты поиска |
| `schemeStyle` | рамки, текст, отступы |
| `pdfExport` | страницы PDF |
| `fileNaming` | имена схем и файлов |
| `storage` | localStorage и версия JSON |
| `i18n` | русские и английские подписи |

## Правило стадий размера

- `beforeTrim`: зачистка применяется;
- `afterTrim`: зачистка уже учтена и повторно не применяется.

## Значения по умолчанию

- язык: `ru`;
- единицы: `mm`;
- зачистка: включена, 2 мм с каждой стороны;
- поля: 4 / 4 / 2 / 13 мм;
- переворот: горизонтальный слева направо;
- режим оборота: отдельные лицо и оборот;
- первый приоритет: минимум бумаги;
- PDF: одна схема на страницу;
- панель настроек: открыта после каждой загрузки.

См. рабочий пример в `src/config.example.js`.
