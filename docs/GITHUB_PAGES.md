<h2>Русский</h2>

<p>Целевой адрес:</p>

<p><code>https://sunpole.github.io/uImposition/</code></p>

<p>В репозитории предусмотрен workflow <code>.github/workflows/pages.yml</code>.</p>

<ol>
<li>Открыть <strong>Settings → Pages</strong>.</li>
<li>В разделе <strong>Build and deployment</strong> выбрать <strong>GitHub Actions</strong>.</li>
<li>Убедиться, что ветка <code>main</code> содержит <code>index.html</code>.</li>
<li>Открыть вкладку <strong>Actions</strong> и проверить workflow <strong>Deploy GitHub Pages</strong>.</li>
<li>После успешного запуска открыть целевой адрес.</li>
</ol>

<p>Если подключённое приложение не имеет права менять Pages, этот шаг выполняет владелец репозитория вручную.</p>

<h2>English</h2>

<p>Target URL:</p>

<p><code>https://sunpole.github.io/uImposition/</code></p>

<p>The repository contains <code>.github/workflows/pages.yml</code>.</p>

<ol>
<li>Open <strong>Settings → Pages</strong>.</li>
<li>Select <strong>GitHub Actions</strong> under <strong>Build and deployment</strong>.</li>
<li>Confirm that <code>main</code> contains <code>index.html</code>.</li>
<li>Open <strong>Actions</strong> and inspect <strong>Deploy GitHub Pages</strong>.</li>
<li>Open the target URL after a successful deployment.</li>
</ol>

<p>If the connected application cannot change the Pages source, the repository owner must complete this step manually.</p>
